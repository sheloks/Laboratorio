# 🦷 Laboratorio

Sistema de gestión integral para laboratorio dental desarrollado por **Datasoluciones**.

## 📋 Descripción

Software diseñado para administrar las operaciones de un laboratorio dental, incluyendo gestión de órdenes, clientes, usuarios y más.

## 🚀 Tecnologías

### Frontend
- Vue.js 3
- TypeScript
- Vite

### Backend
- Java
- Spring Boot
- Spring Security + JWT
- Base de datos relacional

## ⚙️ Instalación

### Requisitos previos
- Node.js 18+
- Java 17+
- Maven

### Backend
```bash
cd backend
./mvnw spring-boot:run
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
